The folder factory

A dark factory where AI agents do the work, and every claim is backed by evidence.

bandit runs Claude Code, opencode, Codex, pi — any harness — on one kanban board: cards, a mechanical verify gate, a consult thread that argues before it executes, and a confidence ledger that turns experience into established truth.

Install Installation guide

01 / THE LOOP

Consult first. Execute. Verify mechanically. Then decide.

A bounded convergence dialogue per card: the critic argues the plan before execution tokens burn, the actor works, the gate re-runs the verification command itself, and the master routes on the full thread.

02 / ORGANS

Measure, argue, decide — no organ holds two of those roles.

The Goodhart boundary is structural: the machine that says done is never the machine that did the work, and the grader never joins the room it grades.

SEAT

The classifier seat

Grades criterion-by-criterion in one cheap call. Fixed prompt, no persona, track record in .bandit/grading/. Self-reported confidence is recorded as fiction whenever the gate disagrees — and the dossier flags it.

PEER

The critic — and the summoned voices

Argues free text in the consult thread, ends with one DECISION line, and may summon a researcher or architect into the conversation. Spawned serfs register as children — the audit is a file, not a process leak.

ROUTER

The master

Owns the conversation and the routing decision: retry, specialist, escalate. Consults the critic at plan time and on stagnation. Decides with the best argument in the room — the thread is the receipt.

03 / VISIBILITY

Walk the factory the way the loop does.

One command per altitude. All projection over files — no client holds state, no viewer can corrupt the factory.

WAVE

bandit watch

A live wave view that subscribes to the event stream — stage, role, gate per in-flight card, the last consult exchange with summoned voices in magenta. Renders on append; never polls.

DOSSIER

bandit card <id>

What happened to this card: timeline, consult thread as a chat, per-round grading with contradictions flagged, artifacts with sizes. Every section cites its file.

PROOF

bandit doctor

Nine-point health check, exit 1 on failure — CI-safe. The factory on itself found and fixed three of its own defects while the dossier narrated every round.

04 / DISCIPLINE

No new mechanism without a measured trigger.

The KISS ledger is the factory's regularization: what is kept (each row earned by a real failure), what is frozen (with the exact production trigger that thaws it), what is forbidden (self-grading loopholes, by construction). Overfitting is the failure mode before floor-creep — this is the harness that doesn't fit itself to anecdotes.

kept     event sourcing · budget caps · the mechanical gate · the consult thread
frozen   TD prediction · forests · multi-voice debate — each behind a measured trigger
forbidden  learned floors · the grader in the room it grades · conversation over the gate

05 / START

Keep your agents. Change the factory.

bandit wraps whatever harness answers the prompt. Local ollama, zero cloud tokens — or your existing Claude/opencode/Codex login.

$ git clone https://github.com/wisbech/bandit.git && cd bandit && bun install && bun run build
$ cd your-project
$ bandit init
$ bandit task "write a hello world module" --accept "module prints HELLO_WORLD"
$ bandit start --once
$ bandit doctor   # 9 checks — healthy
$ bandit watch    # walk the floor
